# 🚀 Stylish English (ستايليش إنقلش)

منصة تفاعلية لتعليم اللغة الإنجليزية للمبتدئين في العالم العربي، تعتمد على التفاعل الصوتي المباشر والذكاء الاصطناعي مع منهج مخصص ومقسم على مدار 3 أشهر.

---

## ✨ المميزات الرئيسية

* 📚 **منهج شامل من 36 درساً:** مقسّم هندسياً على 3 أشهر (12 درساً شهرياً) يتدرج من الأساسيات حتى المحادثة.
* 🎙️ **معلم ذكي متكلم (Alexa):** محادثات صوتية فورية وحية تدعم الممارسة المباشرة واستماع النطق الصحيح.
* 🇸🇦 **لهجة سعودية بيضاء تبسيطية:** نظام محادثة مصمم ليفهم ويعين المستخدم العربي بأسلوب سلس ومباشر.
* 🏆 **نظام XP وتحديات موحدة:** تتبع الإنجاز، المكافآت، والمستويات مع حفظ التقدم تلقائياً.
* ⚡ **أداء خفيف وسريع:** واجهة مصممة لتعمل بسلاسة عالية على الأجهزة الذكية وجهاز الكمبيوتر.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6), Web Audio API / WebGL Visualizer.
* **Backend:** Node.js (WebSocket Relay).
* **AI Integration:** Gemini Live API for real-time speech interaction.
* **Hosting:** Vercel (Frontend) & Render (Backend Relay).
